# yuxino

I've been building since 2015 — C → Java → the web → AI. Still at it.

## currently building

- [`mimi`](https://github.com/yuxino/mimi) — live translated subtitles on macOS
- [`meow`](https://github.com/yuxino-labs/meow) — versioned release & hosting for web projects
- [`wnacg`](https://github.com/yuxino/wnacg) — manga reader with local OCR + AI translation
- [`ding-frame`](https://github.com/yuxino/ding-frame) — video analysis tool that understands frames
- [`satori`](https://github.com/yuxino/satori) — local-first PDF reader with AI explanations
- [`kiri`](https://github.com/yuxino/kiri) — screenshots & notes that don't vanish with the clipboard

## before that

I've built my own versions of MVVM, React, Promise, SSR, and a tiny Java HTTP server.

A couple of my patches are in [Lodash](https://github.com/lodash/lodash/pull/3467) and [Redux](https://github.com/reduxjs/redux/pull/2976).

2015 → now. Some projects survived; most became stories — I write about the recent ones at [ashita.yuxino.cn](https://ashita.yuxino.cn).
