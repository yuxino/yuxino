## RECENTLY

I have been building a lot of small things with AI.

At first they were just separate projects. Then they all needed the same boring things: auth, APIs, deployment, versioning, shared components, and somewhere to live. So I made [`yuxino-labs`](https://github.com/yuxino-labs) and slowly turned it into my own tiny software studio.

A few things that are still alive:

- **`mimi`** *(private)* — Live translated subtitles for macOS. This is the new one.
- **`meow`** *(private)* — A release dashboard for my web projects. It can create projects, trigger GitHub Actions, publish builds to OSS, switch versions, manage runtime scripts, and delete things when I regret creating them.
- **`nichijou`** *(private)* — A personal daily-life journal. Posts, photos, memories, comments, search, focus, badges, and more image handling than I expected.
- **`yomi`** *(private)* — A visual workflow editor with nodes, branches, logs, and runtime settings.
- **`paw`** *(private)* — A web file explorer.
- **`ele`** *(private)* — A meal photo diary. Mostly evidence that I did eat today.
- **`comet`** *(private)* — A personal board app. It accidentally became the reason I built the whole release system around it.
- **`x`** *(private)* — A small mobile expense tracker. The name is not very searchable, but it is short.

Some side projects became more serious than planned:

- **`deepsuck`** *(private)* — Use Claude Code on my Mac from my phone through Next.js, SSE, and an FRP tunnel. Basically full shell access from bed. Very convenient, slightly concerning.
- **`tick`** *(private)* — A Tauri app for managing macOS `launchd` jobs. It also has Miku in the menu bar, which helps.
- **`wnacg`** *(private)* — A Tauri desktop reader with themes, preloading, and fallback mirrors.
- **`ashita`** *(private)* — A personal timeline that started from a docs template and stopped being one a long time ago.
