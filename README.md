## GRAVEYARD

- [2048](https://github.com/yuxino/2048) — 2048, but in Vue. It reached 2048 and had nothing left to prove.
- [dashboard](https://github.com/yuxino/dashboard) — A beautiful Vue dashboard from the era when every dropdown deserved to be built by hand. The dropdown reached 100%; the story ended there.
- [flutter_npass](https://github.com/yuxino/flutter_npass) — One Flutter client, one init commit, one very short life. It died before the README stopped being a template.
- [lemuro](https://github.com/yuxino/lemuro) — My small pile of filesystem helpers. The boring code is somebody else's problem now.
- [mobile-pdf-viewer](https://github.com/yuxino/mobile-pdf-viewer) — Built because Android WeChat refused to open PDFs. It did its job; even the progress bar was forgiven.
- [ob](https://github.com/yuxino/ob) — An Observer exercise that became a tiny MVVM. `just enough.` was the last real word, and enough it was.
- [osu](https://github.com/yuxino/osu) — A Flutter currency converter for the hot countries XD. The exchange rates kept moving; the app did not.
- [pyfl](https://github.com/yuxino/pyfl) — Not a lightweight way to get the first letters of Chinese pinyin, but it worked. 38 stars came to the funeral.
- [react-scratch](https://github.com/yuxino/react-scratch) — A simple React scratch-card component. Scratched once, finished, left under the silver dust.
- [sicp-ex](https://github.com/yuxino/sicp-ex) — My SICP exercises in Racket. Exercise 2.29 fought hard; both of us eventually went home.
- [the-scripts](https://github.com/yuxino/the-scripts) — It showed the scripts in `package.json` and ran them on click. Then one day, nobody clicked.
- [vido](https://github.com/yuxino/vido) — A moe-flavored video player from the Vue 1.x age. It briefly sat up in 2026; this was only a muscle spasm.
- [viva](https://github.com/yuxino/viva) — A desktop Markdown editor. The editor went quiet; the Markdown survived.
- [vscode-pdf-reader](https://github.com/yuxino/vscode-pdf-reader) — An unpublished VS Code PDF reader trying to fix pdf.js with more pdf.js. 然并卵。卒。
- [vue-typescript-starter](https://github.com/yuxino/vue-typescript-starter) — A Vue + TypeScript starter from 2017. The ecosystem moved house and forgot to leave an address.
- [WeChat](https://github.com/yuxino/WeChat) — A WeChat client built with Vue. 算了就酱紫，没做的再说吧。
