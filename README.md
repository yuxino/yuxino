## LATELY

I make things mostly for myself. Sometimes I need them. Sometimes I just want to see whether I can make them. Quite a few projects end somewhere in between.

**`nichijou`** keeps ordinary days, **`ele`** keeps meals, and **`ashita`** — “tomorrow” — keeps the longer timeline. I seem to enjoy making software for remembering things, possibly because I am not very good at remembering them myself.

**`mimi`** does live translated subtitles because teenage me wanted to understand Japanese AV instead of guessing. **`wnacg`** started because I wanted to learn Tauri and needed something to build, so I made a doujin reader. I worked on it for quite a while and, yes, jerked off a lot while testing it.

**`deepsuck`** began as a DeepSeek desktop client when V4 appeared. The name was only a couple of letters off. Then Claude Code's leaked source showed up, I got distracted, and almost the whole project became a way to use local Claude Code from my phone. In hindsight, the name may have been trying to tell me something.

**`comet`** is another idea that refused to disappear. Years earlier I had **`task-daily`**, a small app for recording tasks. AI changed how fast I can build it, but apparently I still need to write software to tell myself what to do.

**`meow`** is separate from `comet`. It is the release infrastructure for the frontends I keep producing in the AI era: projects, builds, immutable versions, instant switching and rollback, runtime script injection, and a gateway that decides what actually goes live. It is fairly serious infrastructure with the name and temperament of a cat.

The names are part of the memory too. **`yomi`** is Yuumi from *League of Legends*. **`ashita`** means tomorrow. **`lemuro`** came from Rimuru. **`vido`** belongs to the period when I was learning Vue and liked Miku very much. I like cute characters, cats, and names that sound a little Japanese. There is no naming system. There was just whatever I liked at the time.

## BEFORE AI COULD TYPE THIS FAST

I was already learning by making things, just more slowly.

[**vido**](https://github.com/yuxino/vido), [**WeChat**](https://github.com/yuxino/WeChat), [**dashboard**](https://github.com/yuxino/dashboard) and [**2048**](https://github.com/yuxino/2048) came from the years when learning frontend mostly meant rebuilding things I could see.

**`miaohu`** was my attempt to rebuild Zhihu when I had only just started programming. I wrote a surprisingly large part of the backend API. The friend doing the frontend kept procrastinating, so the backend waited patiently until the whole project died.

I have also rebuilt the same kind of personal site more times than I can count. The oldest **`blog`** greeted visitors with “Life's a Movie.” because I was very into rap at the time. Then came **`meteorite`**, a blog system built around GitHub Issues, then **`moment`**, and eventually **`ashita`**. The frameworks changed. The urge to leave a record did not.

Later I started rebuilding the parts underneath: [**ob**](https://github.com/yuxino/ob), several tiny React attempts, SSR experiments, [**promise_impl**](https://github.com/yuxino/promise_impl), [**y-language**](https://github.com/yuxino/y-language), and **`Marisa`**, a Java web server. I also opened SICP and algorithm books with great enthusiasm. I reached exercise 2.29. The books were patient when I left.

There was a period when I would wander into other people's frameworks and send patches too. A small fix made it into [Lodash](https://github.com/lodash/lodash/pull/3467), and another change made it into [Redux](https://github.com/reduxjs/redux/pull/2976). I also tried things in [Vite](https://github.com/vitejs/vite/pull/219), [VitePress](https://github.com/vuejs/vitepress/pull/116), [Taro](https://github.com/NervJS/taro/pull/4334), [iView](https://github.com/iview/iview/pull/5413), [Zustand](https://github.com/pmndrs/zustand/pull/785), and quite a few smaller projects. Some patches landed. Some did not. Some of those projects disappeared; others grew into things much bigger than the version I once poked at.

Some ideas kept returning in different clothes. One password manager became server, SwiftUI and Flutter versions. `task-daily` came back as `comet`. A blog kept reincarnating until it became `ashita`.

There were smaller things too: [**mobile-pdf-viewer**](https://github.com/yuxino/mobile-pdf-viewer), [**vscode-pdf-reader**](https://github.com/yuxino/vscode-pdf-reader), [**the-scripts**](https://github.com/yuxino/the-scripts), [**pyfl**](https://github.com/yuxino/pyfl), [**lemuro**](https://github.com/yuxino/lemuro), bots, snippets, clones, half-finished frameworks, an empty **`ghost`**, and a repository literally named **`-`**.

I have been learning for a long time. I have also been abandoning projects for a long time.

Sometimes I stopped because I had learned enough. Sometimes the other half of the project never arrived. Sometimes something newer or cuter appeared. Sometimes the same unfinished idea crossed several years and came back with different code.

They are not really a career story. They are just my memories, with dependencies.
