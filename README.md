## RECENTLY

I've been making small personal apps again, mostly with Codex and Claude.

The pattern is familiar: I want a tool, make one, then notice the next project needs the same auth, API, deployment and release setup. So [`yuxino-labs`](https://github.com/yuxino-labs) gradually became the place where the apps live — along with the machinery that keeps them alive.

A few things I still care about:

- **`mimi`** *(private)* — Live translated subtitles for macOS.
- **`nichijou`** *(private)* — Posts, photos and small pieces of daily life. A quiet place to remember things before I forget them.
- **`comet`** *(private)* — A personal board app. It also caused most of the release system around it, which was not in the original plan.
- **`meow`** *(private)* — The dashboard I now use to create, build and publish those web projects.
- **`yomi`** *(private)* — A visual workflow editor. Apparently boxes and arrows make complicated things feel negotiable.
- **`ele`** *(private)* — A meal photo diary. Mostly proof that I ate something other than takeout packaging.

And a few tools I made because existing ones were close, but not close enough:

- **`deepsuck`** *(private)* — Use Claude Code on my Mac from my phone.
- **`tick`** *(private)* — Manage macOS `launchd` jobs without editing plist files by hand. Miku is in the menu bar for operational support.
- **`paw`** *(private)* — A web file explorer.

## BEFORE AI COULD TYPE THIS FAST

Most of my older projects were ways to understand something by rebuilding part of it.

- [**vido**](https://github.com/yuxino/vido) — A custom video player built with Vue 1.x.
- [**WeChat**](https://github.com/yuxino/WeChat) and [**dashboard**](https://github.com/yuxino/dashboard) — The years when learning frontend mostly meant rebuilding interfaces I already used.
- [**ob**](https://github.com/yuxino/ob) — An Observer exercise that slowly became a tiny MVVM implementation.
- **`react-mini`** *(private)* — A small React implementation. Getting `useState` to work was enough adventure for one repository.
- **`vue-ssr`** *(private)* — My attempt to understand SSR by building the important parts instead of reading another explanation.
- **`Marisa`** *(private)* — A Java web server written to learn routers, annotations and thread pools.
- [**sicp-ex**](https://github.com/yuxino/sicp-ex) — SICP exercises in Racket. I made it to 2.29.

There were also practical tools that survived because they solved annoyingly specific problems:

- [**mobile-pdf-viewer**](https://github.com/yuxino/mobile-pdf-viewer) — Open PDFs inside Android WeChat.
- [**vscode-pdf-reader**](https://github.com/yuxino/vscode-pdf-reader) — A VS Code PDF reader built on pdf.js. Using pdf.js to work around pdf.js went about as expected.
- [**the-scripts**](https://github.com/yuxino/the-scripts) — Browse and run scripts from `package.json`.
- [**pyfl**](https://github.com/yuxino/pyfl) — Get the first letters of Chinese pinyin in the browser. Bigger than necessary, but it worked.

The rest are still here somewhere: unfinished password managers, abandoned blogs, half-built frameworks, an empty repository named `ghost`, and another one literally named `-`.

They were not all useful, but most of them taught me something. That was usually the point.
