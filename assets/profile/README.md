# Profile artwork

- `intro-light.svg` and `intro-dark.svg`: original typography for this profile. Display lettering is outlined from DM Serif Display by Colophon Foundry; its SIL Open Font License is included alongside these files. The small labels use the viewer's monospace font.
- `kiri-in-use.gif`: copied unchanged from `yuxino/kiri`, `docs/demos/preview.gif`. See that repository's demo provenance.
- `satori-in-use.gif`: copied unchanged from `yuxino/satori`, `docs/demos/preview.gif`. See that repository's demo provenance.
- `mimi-film.webp`: copied unchanged from the Mimi website's English full-tour poster. This is a character illustration, not a screenshot. Its link opens the actual product demonstration.

Project icons in `../projects/` are the existing artwork of their respective projects. The profile does not depend on external statistics-card or badge services.

The Kiri and Satori still images are unchanged existing poster assets, used when the viewer requests reduced motion.
