# Portfolio panels

SVG layouts combine unchanged project posters and website screenshots documented in ../README.md and ../FEATURE-SOURCES.md. Project names use outlined DM Serif Display; the font license is in the parent directory. Descriptions use English and Chinese live SVG text, except Blue Whale Maid, which remains Chinese by request. Light and dark variants match GitHub themes.

The main panel links to source; the separate footer links to the website. Each image has a descriptive text alternative in the profile README.

## Website captures, 2026-09-20

- `../satori-website.png`: https://satori.yuxino.cn/ at 1200 × 750. English website hero, not an app screenshot. The app UI itself is Chinese.
- `../osu-website.png`: https://osu-web.yuxino.cn/en.html at 1200 × 800, release 1, source 65ae597. Website hero with character and illustrative captions, not native device acceptance evidence.

Both were captured directly in Ego Lite. Existing character art was retained unchanged.
