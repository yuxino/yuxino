# Portfolio panels

SVG layouts combine unchanged project posters and website screenshots already documented in ../README.md and ../FEATURE-SOURCES.md. Project names use outlined DM Serif Display; the font license is in the parent directory. Chinese descriptions are live SVG text. Light and dark variants match GitHub themes.

The main panel links to source; the separate footer links to the website or installation instructions. Each image has a descriptive text alternative in the profile README.
