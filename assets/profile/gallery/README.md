# Portfolio panels

SVG layouts combine unchanged project posters and website screenshots documented in ../README.md and ../FEATURE-SOURCES.md. Project names use outlined DM Serif Display; the font license is in the parent directory. English and Chinese descriptions use live SVG text; Blue Whale Maid remains Chinese by request. Light and dark variants match GitHub themes.

The main panel links to source; the separate footer links to the website. Each image has descriptive alternative text in the profile README.
