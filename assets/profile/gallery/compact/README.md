# Compact profile gallery

The profile uses the existing project images directly, followed by a 600 × 64 caption and a 600 × 24 website link. This replaces the tall, self-contained 600 × 510 panels and their 600 × 52 website footers. Original images and legacy panels are retained.

Captions use a 30px serif project name, a 17px English summary on the same line, and an 18px Chinese summary below. Light and dark variants use transparent backgrounds. The website footer uses 17px text instead of the previous 28px text.

All images render at 49% width without a fixed height, preserving their aspect ratios. No external image services, generated screenshots, cropped artwork, or workflows are required.

The two-column order is Kiri / Mimi, Fuwa / Tick, Koma / Pyfl, Vido / Osu. The compact text links below remain unchanged.
